# ASSET-CREDITS — The Long Trail

All images in `res://assets/art/` were sourced from Wikimedia Commons on 2026-08-04. Each file's
license tag was verified via the Commons API (`LicenseShortName`) at download time; only files tagged
**Public domain**, **CC0**, or **No known restrictions** were kept. Watermark/credit-banner QC was done
visually on every file.

**Attribution requirements:** none of these licenses *legally require* attribution (public domain and CC0
impose no conditions; DPLA/NARA/LOC "no known restrictions" likewise). Courtesy credit is still good
practice — shipping this file (or a credits screen generated from it) in the game satisfies that fully.
Where an institution requests a courtesy line, it is noted per-asset below.

Raw manifest with QC notes: `res://assets/art/MANIFEST.md`. A duplicate staging copy of this art lives at
`Desktop\Apps\westward\assets\art` (HTML prototype) — the res:// copies are canonical for this project.

## Known gaps (see MANIFEST.md "Skipped subjects")
No clean public-domain match was found for: coffee pot, tombstone/boot hill, standalone playing-card faces,
calm prairie landscape, gold coins. If generating replacements with Summer's asset tools, match the style:
black-ink 19th-century engraving/woodcut on plain background, no color washes.

## Rules for adding future assets
Every new file added under `res://assets/` gets a row in this table **in the same commit**: res:// path,
original source URL (or "generated in Summer" with the prompt), license, attribution requirement, intended use.
"Publicly available" ≠ unrestricted — verify the license tag before downloading, skip anything unclear.
